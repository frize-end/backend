# 企业内部资源管理中台
## 项目说明
本项目为企业自研内部资源管理中台，基于 FastAPI 构建轻量化、高扩展的企业级后端架构，旨在解决企业软硬件资源分散管理、数据孤岛、流程线下化、管控无溯源等痛点，搭建企业唯一可信的内部资源管控底座。
## 核心定位
统一纳管企业全品类软硬资源，实现资源台账数字化、审批流程线上化、权限管控标准化、数据服务中台化。
•	管理中台：覆盖资源申领、调拨、使用、归还、报废全生命周期管控
•	数据中台：统一资源数据标准，对外提供标准化 API 数据服务
•	安全中台：基于 RBAC 权限体系，实现全员操作审计、权限隔离
## 技术栈
后端核心（已落地）
•	框架：FastAPI（高性能异步、原生接口文档、类型校验）
•	ORM：SQLAlchemy 2.0
•	数据库：MySQL 8.0
•	环境管理：python-dotenv 多环境隔离
•	工程规范：分层依赖管理、Git 规范、Ruff 代码校验
后续迭代中间件
Redis（缓存/限流）、APScheduler（定时预警）、消息队列（异步通知）
## 核心功能模块
• 组织权限模块：部门、用户、角色、RBAC 权限管控
• 资源台账模块：全品类软硬件资源统一登记、分类、状态管理
• 流程审批模块：资源申领、调拨、归还、报废线上审批流
• 数据看板模块：资源存量、闲置率、分类占比数据统计
• 审计日志模块：全操作行为记录、变更溯源、内控审计
• 开放中台接口：对外标准化数据服务（远期迭代）
## 环境搭建
1. 创建虚拟环境
python -m venv .venv
2. 激活虚拟环境
Windows Powershell: .venv\Scripts\Activate.ps1
3. 安装依赖
pip install -r requirements-base.txt
## 启动服务
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
## 接口文档地址
• 交互式调试文档：http://127.0.0.1:8000/docs
• 静态官方文档：http://127.0.0.1:8000/redoc
## 项目价值
消除企业资源数据孤岛、降低资产闲置成本、标准化内部审批流程、全链路操作安全溯源，为企业内部数字化管控提供标准化中台底座，可长期迭代复用。
